# Workflow

> Load when starting new work or planning

1. **Read context** — check `backlog/` + `inprogress/` first
2. **Plan** — create todo list before starting (large tasks)
3. **Execute** — read files before editing
4. **Test (loop until pass)** — build+test → fix → repeat (notify boss after 3 failed rounds)
5. **Review + deliver** — build passes, summarize + git commit

- **Ask first:** unclear requirements, multiple trade-off approaches, impacts major structure
- **Just do it:** clear task, bug fix, small feature, style tweak
- **Proactive:** spot a bug/security risk → notify boss immediately
- **Research:** always find best practice first / bug after 2 rounds → search GitHub Issues, Stack Overflow
