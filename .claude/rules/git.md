# Git Rules

> Load when committing, branching, or managing version control

- 1 commit = 1 thing — `<type>(<scope>): <subject>` — English only
- Never commit code that fails to build / secrets / `.env`
- After task done → auto `git add` + `commit` — **always ask boss before push**
- Branches: `main` = prod, `develop` = staging, `feature/xxx`, `fix/xxx`
- **No Co-Authored-By or any Claude credit in commit messages** — keep commits clean
