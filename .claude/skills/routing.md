# 🤖 Agent Routing — Master Index

> เมื่อบอสพูดถึง topic ใด → หา group ที่ตรง → อ่าน group file → เรียก command ที่เหมาะสม
> ถ้าต้องการ deep skill → ดู "Deep Skills" section ใน group file → อ่าน SKILL.md ตาม path

## How to Route
1. บอสพูดถึง topic → match keyword กับ group table ข้างบน
2. อ่าน group file → หา command ที่ตรงที่สุด
3. ถ้า group มี Deep Skills ที่ตรง topic → อ่าน SKILL.md ตาม path ก่อนตอบ
4. เรียก command / ใช้ skill knowledge ตอบบอส
