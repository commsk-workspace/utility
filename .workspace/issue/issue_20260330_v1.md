# Hub Issues — (2026-03-30)

## Issue-001: Avatar ใน MapEditor เดินไม่ได้ (ไม่เห็นตัวละคร)
- **Found at:** `.hub/tracker/client/src/components/MapEditor.jsx` — avatar preview feature
- **Symptom:** เปิด Avatar toggle แล้วกด WASD/Arrow keys ไม่เห็นตัวละครเดิน (เห็นแค่ shadow เล็กๆ หรือไม่เห็นอะไรเลย)
- **Cause:** `generateLPCCharacter()` โหลด sprites จาก `/lpc-sprites/...` ซึ่งไม่มีอยู่ใน `public/` → ทุก image load fail → return blank transparent canvas → `ctx.drawImage` วาดแต่ transparency → ไม่เห็น sprite
- **Fix:** เพิ่ม `generateFallbackAvatarSheet()` ใน MapEditor.jsx ที่สร้าง walk spritesheet แบบ programmatic (canvas 2D, ไม่ต้องใช้ external files) — เหมือน `BootScene.generateCharacterSprites()` แล้ว set ทันทีเมื่อ showAvatar=true
- **Status:** Fixed
- **Fix applied:** Added `generateFallbackAvatarSheet()` (line 66-124 in MapEditor.jsx) — programmatic walk spritesheet ไม่ต้องใช้ external files + set ทันทีเมื่อ `showAvatar=true`

## Issue-002: KanbanBoard ไม่ใช้ workspaceDir เป็น path จริง
- **Found at:** `.hub/tracker/client/src/components/KanbanBoard.jsx` + `SystemView.jsx`
- **Symptom:** KanbanBoard ใช้ `system` (ชื่อ system) เป็น folder path ตรงๆ แต่ `workspaceDir` ใน DB อาจต่างจากชื่อ system ทำให้ดึง cards ผิด folder และสร้างไฟล์ผิด path
- **Cause:** `SystemView` ส่ง `system={system}` (route name) ไปให้ `KanbanBoard` แต่ไม่ได้ส่ง `workspaceDir` — ขณะที่ `PlanTab`, `SystemTerminal`, `SystemInfoPanel` ทุก tab ใช้ `systemData?.workspaceDir || system` อยู่แล้ว
- **Fix:** เพิ่ม prop `workspaceDir` ให้ `KanbanBoard` และใช้มันสำหรับ API calls + file path construction แทน `system`; `SystemView` ส่ง `systemData?.workspaceDir || system` เป็น prop ใหม่
- **Status:** Fixed
- **Fix applied:** เพิ่ม `workspaceDir` prop ใน `KanbanBoard.jsx` (line 162-164) + `SystemView.jsx` ส่ง `systemData?.workspaceDir || system` — card load/create/move/plan ทั้งหมดใช้ `wsDir` แทน `system` สำหรับ path
