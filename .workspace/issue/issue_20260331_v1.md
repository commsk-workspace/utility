# DevTools Utility Issues — (2026-03-31)

## Issue-001: SVG Optimizer XSS vulnerability (dangerouslySetInnerHTML)
- **Found at:** `src/app/svg/page.tsx:234-237`
- **Symptom:** User-supplied SVG rendered via `dangerouslySetInnerHTML={{ __html: output }}` without sanitization
- **Cause:** `optimize()` function only does structural cleanup but does NOT strip event handlers or `<script>` tags
- **Fix:** Added `sanitizeSvg()` function that strips on* event handlers, script tags, javascript: URIs, foreignObject, and data: URIs before rendering
- **Status:** Fixed
- **Severity:** Critical

## Issue-002: API Tester CORS limitations not communicated
- **Found at:** `src/app/api-tester/page.tsx:102`
- **Symptom:** Requests to external APIs fail with "Failed to fetch" — no CORS warning shown
- **Cause:** Client-side fetch without server-side proxy, generic error handler doesn't distinguish CORS errors
- **Fix:** Added CORS warning banner + "Use Proxy" toggle + server-side proxy route (`/api/proxy/route.ts`) with SSRF protection (blocks private network requests) + CORS-specific error detection
- **Status:** Fixed
- **Severity:** Medium

## Issue-003: JWT Decoder lacks signature verification
- **Found at:** `src/app/jwt/page.tsx:50-86`
- **Symptom:** Badge shows "VERIFY SIGNATURE" but no verification is performed
- **Cause:** Only base64url decoding, no crypto library used
- **Fix:** Changed badge from "VERIFY SIGNATURE" to "ENCODED SIGNATURE" + added disclaimer text explaining signature verification requires secret key and should be done server-side
- **Status:** Fixed
- **Severity:** Medium

## Issue-004: JS Minifier uses regex — breaks valid JS
- **Found at:** `src/app/minify/page.tsx:57-76`
- **Symptom:** Minified JS can produce syntax errors
- **Cause:** Lookbehind regex (ES2018), over-aggressive space removal around operators
- **Fix:** Replaced lookbehind with compatible `(^|[^:])` pattern, changed approach to join statements with semicolons instead of removing all spaces around operators, added redundant semicolon cleanup
- **Status:** Fixed
- **Severity:** Low

## Issue-005: CSV header parsing inconsistent with body parsing
- **Found at:** `src/app/csv/page.tsx:37`
- **Symptom:** CSV headers with quoted values containing delimiters split incorrectly
- **Cause:** Headers used basic `.split(delimiter)` but body used proper `parseCSVLine()`
- **Fix:** Changed line 37 to use `parseCSVLine(lines[0], delimiter)` for consistency
- **Status:** Fixed
- **Severity:** Low
