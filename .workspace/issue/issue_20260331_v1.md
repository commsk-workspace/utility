# DevTools Utility Issues — (2026-03-31)

## Issue-001: SVG Optimizer XSS vulnerability (dangerouslySetInnerHTML)
- **Found at:** `src/app/svg/page.tsx` (preview section)
- **Symptom:** User-supplied SVG is rendered via `dangerouslySetInnerHTML` without sanitization
- **Cause:** No SVG sanitization library is used before rendering user input
- **Fix:** Add SVG sanitization (e.g., DOMPurify) before rendering preview, or use a sandboxed iframe
- **Status:** Open
- **Severity:** Critical

## Issue-002: API Tester CORS limitations not communicated
- **Found at:** `src/app/api-tester/page.tsx`
- **Symptom:** API requests to external endpoints fail silently due to browser CORS restrictions
- **Cause:** Client-side fetch cannot bypass CORS; no proxy route is provided
- **Fix:** Add a server-side proxy route (`/api/proxy`) or display clear CORS warning in UI
- **Status:** Open
- **Severity:** Medium

## Issue-003: JWT Decoder lacks signature verification
- **Found at:** `src/app/jwt/page.tsx`
- **Symptom:** JWT tokens are decoded without verifying the signature, giving false sense of validity
- **Cause:** Only base64 decoding is performed, no HMAC/RSA verification logic exists
- **Fix:** Add optional secret key input to verify HS256/RS256 signatures
- **Status:** Open
- **Severity:** Medium

## Issue-004: JS Minifier uses basic regex (not production-grade)
- **Found at:** `src/app/minify/page.tsx` (line ~62)
- **Symptom:** Complex JS code may be incorrectly minified (regex-based comment removal can break strings)
- **Cause:** Uses simple regex instead of proper AST-based minification
- **Fix:** Use terser library for JavaScript minification
- **Status:** Open
- **Severity:** Low

## Issue-005: CSV parser doesn't handle complex escaping
- **Found at:** `src/app/csv/page.tsx` (line ~37)
- **Symptom:** CSV with quoted fields containing commas or escaped quotes fails to parse correctly
- **Cause:** Basic `.split(delimiter)` approach doesn't handle RFC 4180 edge cases
- **Fix:** Use papaparse library for proper CSV parsing
- **Status:** Open
- **Severity:** Low

## Issue-006: Homepage only shows 8 tools (missing 16+)
- **Found at:** `src/app/page.tsx` (tools array, lines 17-92)
- **Symptom:** Homepage dashboard only lists 8 tools but project has 24+ tools
- **Cause:** Only 8 tools are defined in the `tools` array on homepage
- **Fix:** Add all remaining tools (CSV, Diff, Regex, Password, URL, Base64, JWT, Gradient, Lorem, API Tester, Minify, Image, Placeholder, SVG, YAML) to the tools array
- **Status:** Open
- **Severity:** Medium
